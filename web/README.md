# Archived Grocery Ledger web prototype

This Vinext application is a retired browser-local prototype. It is retained
only as implementation history.

Do not deploy this directory and do not add new Grocery Ledger features here.
The canonical production web client is `../docs/`; the native iPhone app is
`../GroceryLedger/`.

The prototype's build configuration and tests may be consulted while moving a
useful idea into the production client, but they are not a source of product
truth. The root `README.md` defines the current architecture and privacy
boundaries.
